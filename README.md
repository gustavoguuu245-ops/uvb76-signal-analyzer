# 📡 UVB-76 Signal & Traffic Analyzer (SIGINT & OSINT Pipeline)

Um pipeline completo de **Engenharia de Dados e Inteligência de Fontes Abertas (OSINT)** desenvolvido em Python para ingestão, tratamento, verificação de integridade criptográfica e análise de metadados das transmissões de rádio militar de ondas curtas **UVB-76 (4625 kHz)**.

## 🎯 Objetivo do Projeto

Analisar a atividade de radiofrequência da estação russa UVB-76 através de **análise de tráfego e metadados**, identificando padrões comportamentais, frequência de indicativos e palavras de código (*codewords*) sem a necessidade de quebra de criptografia.
